# Lendo Landing Page

A pixel-perfect and fully responsive clone of the **Lendo** (لندو) landing page, built with a strong focus on mobile-first design, clean layout structures, and interactive user interface components.

## ✨ Key Features
* **Fully Responsive Design:** Optimized for all screen sizes (Desktop, Tablet, and Mobile) with precise Media Queries.
* **Interactive Hero Slider:** Smooth layout adaptation ensuring multi-device consistency.
* **Loan Calculator & Grids:** Structured layout components replicating the original user experience.
* **Modern CSS Layouts:** Utilizing Flexbox and Grid for precise alignment.

## 🛠️ Technologies Used
* **HTML5** (Semantic markup)
* **CSS3** (Custom styling & Responsive Media Queries)
* **JavaScript** (Interactive elements and logic)
* **Bootstrap 5** (via CDN for layout components)
