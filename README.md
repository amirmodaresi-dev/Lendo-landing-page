# Lendo Landing Page

A responsive, interactive recreation of the **Lendo (لندو)** fintech landing page, built with HTML5, CSS3, and Vanilla JavaScript.

This project focuses on creating a modern user interface with a mobile-first approach, Persian RTL layout, interactive components, and a consistent experience across desktop, tablet, and mobile devices.

## ✨ Features

### Responsive User Interface
- Fully responsive layout for desktop, tablet, and mobile screens.
- Sticky navigation header with a glassmorphism effect.
- Mobile off-canvas navigation drawer.
- Responsive layouts using CSS Flexbox and Grid.

### Interactive Hero Slider
- Dynamic hero slider with multiple slides.
- Automatic slide transitions.
- Previous and next navigation controls.
- Pagination dots.
- Touch swipe support for mobile devices.

### Loan Calculator
- Interactive loan amount selector.
- Support for 6, 9, and 12-month repayment periods.
- Real-time calculation of estimated monthly installments and total repayment.
- Loan amount controls with minimum and maximum limits.

### User Interface & Account Demo
- Login and registration modals.
- Demo login functionality.
- User profile dropdown and logout interaction.
- Browser-based user data storage using `localStorage`.

### Loan Request Management
- Add loan requests to a personal request list.
- Display the number of saved requests.
- View and cancel existing requests.
- Store requests separately for each demo user using `localStorage`.

### Additional Interactive Components
- Dark and light theme toggle with saved preferences.
- Interactive FAQ accordion.
- Customer support chat widget with predefined responses.
- Toast notifications for user interactions.
- Keyboard interaction support for selected UI elements.

## 🛠️ Technologies Used

- **HTML5** – Semantic page structure.
- **CSS3** – Custom styling, responsive layouts, CSS Grid, Flexbox, and theme variables.
- **JavaScript (Vanilla JS)** – UI interactions, slider logic, calculator, and browser-based demo functionality.
- **Bootstrap 5.3.2** – Responsive layout utilities and supporting components.
- **Vazirmatn** – Persian typography.

## 🚀 Getting Started

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/amirmodaresi-dev/Lendo-landing-page.git
   ```

2. Open the project folder:

   ```bash
   cd Lendo-landing-page
   ```

3. Open `index.html` directly in your browser, or use the **Live Server** extension in Visual Studio Code.

**Note:** An internet connection is required to load external resources such as Bootstrap, Vazirmatn, and some remote visual assets.
